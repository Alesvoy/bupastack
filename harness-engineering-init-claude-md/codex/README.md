# No Codex equivalent

`harness-engineering-init-claude-md` is Claude Code-specific — it scaffolds a `CLAUDE.md` entry-point as a thin import of `AGENTS.md`.

Codex doesn't have a `CLAUDE.md` concept (it reads `AGENTS.md` directly), so there is no Codex counterpart to mirror here. The Claude version of this skill is the only one that exists.

If you're setting up the harness on a Codex machine, skip this skill — `harness-engineering-project-bootstrap` already creates `AGENTS.md` for you, and Codex will read it natively.
